## 🆘 Troubleshooting

### Problem: "No procedures found"
**Solution:** Try these fixes:
1. Check spelling (e.g., "chestt" won't work)
2. Try a shorter search term (e.g., "xray" instead of "xray chest 2 view pa lateral")
3. Use aliases (e.g., try "c-spine" instead of "cervical")

### Problem: Can't find a specific view option
**Solution:**
1. Search generically first: `xray`
2. Browse all 40 options to see what's available
3. The view you need might be under a different name

### Problem: Modal closed too quickly
**Likely Cause:** You selected an auto-resolve region!
- Clavicle, Femur, and Tibia auto-resolve
- This is intentional - they only have 1 view option
- The CPT code should be auto-filled in the form

### Problem: Wrong CPT code selected
**Solution:**
1. Click "Edit" or re-open the search
2. Make sure you selected the correct:
   - Body region
   - Number of views
   - Special view type (if applicable)

## ❓ Frequently Asked Questions

### Q1: Can I search for MRI and CT scans the same way?
**A:** Yes! The same search engine works for MRI and CT. Just type "mri knee" or "ct head" and it works the same way.

### Q2: What's the difference between "2 Views" and "4 Views"?
**A:** 
- **2 Views** = Standard (usually PA & Lateral)
- **3 Views** = Enhanced (adds oblique or sunrise view)
- **4 Views** = Comprehensive (all angles)

More views = higher CPT code = higher billing.

### Q3: Why do some regions auto-resolve?
**A:** Some body regions only have one standard view option (like Clavicle). Instead of making you click through an extra screen, the system automatically selects it for you!

### Q4: Can I type "AP" or "PA" in my search?
**A:** Yes! The system understands medical terminology like:
- PA (Posterior-Anterior)
- AP (Anterior-Posterior)
- Lateral
- Oblique
- Lordotic
- Flexion/Extension

### Q5: How do I know if I selected the right procedure?
**A:** After the modal closes:
1. Check the CPT code in the form
2. Read the procedure description
3. Verify it matches what was ordered

If wrong, just click "Edit" and search again.

### Q6: What if the procedure I need isn't listed?
**A:** The system includes all Medicare-approved X-Ray CPT codes as of 2024. If you can't find it:
1. Try different search terms
2. Browse all 40 options by searching "xray"
3. Contact your billing department - it might not be a standard X-Ray
