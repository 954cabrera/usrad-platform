Modal Controller Flow Comparison

MRI/CT vs X-Ray Integration

🧲

MRI/CT Flow (Unchanged)

1️⃣ User types "MRI" or "CT"
Modality detected by detectModality()
↓
2️⃣ Contrast Selection
showContrastSelection() → User picks Without/With/Both
↓
3️⃣ Region Selection
showRegionSelection() → User picks Body Part
↓
✅ Immediate Resolution
selectionFlow.resolve() → handleProcedureSelection()
📸

X-Ray Flow (NEW!)

1️⃣ User types "X-Ray"
Modality detected by detectModality()
↓
SKIPPED
2️⃣ Contrast Selection
⚡ X-Ray doesn't use contrast - skip this step!
↓
2️⃣ Region Selection
showRegionSelection('X-Ray') → User picks Body Part
↓
NEW!
3️⃣ View Selection
showXRayViewSelection() → User picks # of Views
↓
✅ Resolution
handleXRayViewSelection() → handleProcedureSelection()
⚡

X-Ray Auto-Resolve (Single View)

1️⃣ User types "X-Ray"
Region selection shown
↓
2️⃣ User clicks "Clavicle"
viewOptions.length === 1 detected
↓
AUTO
⚡ Auto-Resolve
Skip view selection → Immediate resolution to CPT 73000
↓
✅ Done!
Form filled, modal closed
